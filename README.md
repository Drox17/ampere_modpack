# Ampere Modpack

Modpack privado optimizado para Minecraft **1.20.1** (Forge) gestionado mediante **packwiz** y sincronización automática vía GitHub Pages.

---

## 🚀 Guía de Instalación Rápida (Para Jugadores)

Este modpack utiliza un instalador ligero previo al arranque. No necesitas descargar archivos `.jar` manualmente; el launcher sincronizará los mods y configuraciones antes de iniciar.

### Requisitos previos
* **Launcher:** [Prism Launcher](https://prismlauncher.org/) (recomendado) o MultiMC con soporte de cuentas oficiales de Microsoft.
* **Java:** Java 17 (gestionado automáticamente por Prism Launcher).
* **RAM recomendada:** Asignar entre **4 GB** y **6 GB** en los ajustes de la instancia.

---

### Opción A: Importar mediante archivo `.zip` (Recomendado)

1. Abre Prism Launcher.
2. Haz clic en **Add Instance** (Añadir instancia) arriba a la izquierda.
3. Selecciona la pestaña **Import from zip** en el menú lateral.
4. Pega la URL directa del paquete de instalación:
   ```text
   [https://drox17.github.io/ampere_modpack/Ampere_Setup.zip](https://drox17.github.io/ampere_modpack/Ampere_Setup.zip)
